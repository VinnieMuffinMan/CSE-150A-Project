# Milestone 2 Writeup

** Explain what your AI agent does in terms of PEAS. What is the "world" like? **<br/>
The world that the AI agent resides is where the agent is a Blackjack player that aims to maximize their earnings (the performance measure). The world uses an 8-deck size shoe and for each game, it randomly chooses starting hands from this shoe for the dealer and our agent (the environment). Our agent's "sensors" sense the current game state, which consists of the dealer's visible card, the agent's hand, and the cards that we haven't seen based on previous games (i.e. our agent incorporates card counting). Based on the current game state and a large number of observations relevant to that state (i.e. our dataset), the agent's "actuators" chooses the optimal move (hit, stand, double, split, or surrender).

** What kind of agent is it? Goal based? Utility based? etc. **<br/>
Our agent is utility based because it chooses the most effective options in achieving the goal of maximizing earnings.

** Describe how your agent is set up and where it fits in probabilistic modeling **<br/>
Our agent's functionality is found in data_bot.py. The action function takes the current game state as input and generates a large number of possible decks that match the not-seen cards in the state. From this set of possible decks, it creates a dataset of observations by performing possible actions on the deck (hit, stand, etc) and recording their outcomes. The agent incorporates probabilistic modeling by choosing the action A that maximizes the chance of winning a game. Our agent calculates this via expected value, though the underlying principle is maximizing P(success) = (# of successful games with action A)/(# of games).

** Train your first model **<br/>
Our model is trained on the observations that are generated by performing actions on a large number of possible decks.

** Evaluate your model **<br/>
Our model can be evaluated by running data_bot_sim.py, which returns the player's balance after a given number of games and graphs their balance over time.

This first model performs well overall, maintaining a fairly consistent balance throughout the games.
